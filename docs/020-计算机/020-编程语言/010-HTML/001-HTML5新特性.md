# HTML5 带来了哪些新特性?

## 常见问题

- 简述 HTML5 的新特性

## 概念索引

- 语义化标签: 用标签名直接表达内容角色;
- 表单增强: 新输入类型与内建校验;
- 多媒体: audio 与 video 取代外部插件;
- 图形: canvas 与 svg 两种绘制方式;
- 本地存储: localStorage 一类客户端存储接口;
- 新 API: history、WebSocket、Worker 等浏览器能力;

## 语义化标签有哪些?

- 骨架: header、nav、main、article、section、aside、footer;
- main: 页面正文, 一个文档只能出现一次;
- article: 能脱离上下文独立成篇的内容, 如一条新闻;
- section: 正文分段, 通常以标题开头;
- 好处: 结构可读, 利于 SEO 与读屏软件, 但默认样式仍要 CSS 补;

```html
<header><h1>标题</h1></header>
<nav><a href="/">首页</a></nav>
<main>
  <article><h2>一条新闻</h2><p>正文</p></article>
</main>
<footer>版权信息</footer>
```

## 表单增强了什么?

- 新类型: email、url、number、range、date、color、search 等;
- 新属性: placeholder、required、pattern、min、max、step、multiple;
- 内建校验: 提交时自动拦截, 也可用 checkValidity 手动触发;
- 新元素: datalist 给候选, output 显示结果, progress 与 meter 显示进度;

```html
<form>
  <input type="email" required placeholder="邮箱" />
  <input type="number" min="1" max="10" step="1" />
  <input list="cities" />
  <datalist id="cities"><option value="北京"></option></datalist>
</form>
```

- 注意: 内建校验只是体验优化, 服务端必须再校验一次;

## 多媒体与图形怎么用?

- audio 与 video: 自带播放控制条, 加 controls 属性才显示;
- 常用属性: autoplay、loop、muted、preload, video 另有 poster 封面;
- source: 放多个格式, 浏览器取第一个能播的;
- 降级: 标签内部写普通 HTML, 不支持时显示出来;
- canvas: 用 JS 逐像素绘制, 适合图表与游戏, 不适合大段文本;
- svg: 矢量图, 能被 CSS 与 DOM 操作, 缩放不失真;

```html
<video controls poster="cover.png" width="320">
  <source src="a.webm" type="video/webm" />
  <source src="a.mp4" type="video/mp4" />
  <p>浏览器不支持 video 元素</p>
</video>
```

- 自动播放: 多数浏览器要求同时加 muted 才允许自动播放;

## 本地存储与离线能力?

- localStorage: 键值对, 长期保存, 同源共享, 容量约 5MB;
- sessionStorage: 只在当前标签页会话内有效, 关掉就清空;
- IndexedDB: 事务型数据库, 适合大数据量与复杂结构;
- Service Worker: 拦截网络请求, 做离线缓存与消息推送;
- appCache: 已被废弃, 不要再使用;

```js
localStorage.setItem("k", "v");
localStorage.getItem("k"); // "v"
// 只能存字符串, 对象要先 JSON.stringify
```

## 新增了哪些浏览器 API?

- history: pushState 改地址栏而不刷新, 是 SPA 路由的基础;
- WebSocket: 全双工长连接, 适合实时消息;
- Web Worker: 后台线程, 不阻塞主线程渲染;
- 拖放: draggable 属性配合 dragstart、drop 等事件;
- 定位: navigator.geolocation 取经纬度, 需要用户授权;
- 通信: postMessage 在窗口与线程之间传消息;

## 文档头与加载有哪些变化?

- doctype: 只写 `<!DOCTYPE html>`, 不再写长串 DTD;
- 编码: `<meta charset="utf-8">` 放在 head 最前面;
- 视口: viewport 声明让布局宽度跟随设备宽度;
- 脚本: defer 与 async 控制脚本的加载与执行时机;
- 自定义数据: data-* 挂数据, 用 dataset 读取;
- 模板: template 里的内容不渲染, 由 JS 克隆使用;

```html
<meta charset="utf-8" />
<meta name="viewport" content="width=device-width, initial-scale=1" />
<script src="app.js" defer></script>
<div id="box" data-id="7"></div>
```

- 读数据: `document.getElementById("box").dataset.id` 得到 "7";

# 闭包与立即执行函数分别是什么, 各自解决什么问题?

## 常见问题

- 什么是闭包，什么是立即执行函数，它的作用是什么？简单说一下闭包的使用场景
- 简述闭包的概念和应用场景

## 概念索引

- 闭包: 引用了外层函数变量的函数;
- 作用域链: 闭包记住外层环境的机制;
- 变量生命周期: 被闭包引用后, 从"函数结束即销毁"变成"随闭包存活";
- 私有变量: 只能被闭包内方法读写的状态;
- 立即执行函数: 定义后立刻调用的函数表达式, 用来造一次性作用域;
- 模块模式: 用闭包加立即执行函数把私有状态与公开接口分开;

## 闭包是什么?

- 定义: 一个函数引用了它外层函数里的变量, 就形成闭包;
- 形成条件: 内层函数被返回或传出, 且用到了外层的标识符;
- 本质: 函数对象带着创建时的词法环境一起走;
- 边界: 只要还有函数在用它, 外层环境就不会被销毁;

```js
function counter() {
  let count = 0;          // 被闭包引用, 不随 counter 返回而销毁
  return () => ++count;
}
const next = counter();
next(); // 1
next(); // 2; 用的是同一个 count
```

## 闭包为什么能让变量活下去?

- 常规: 函数执行完, 变量对象没人引用, 就可以被回收;
- 闭包: 返回的函数仍持有该环境, 可达性成立, 于是不回收;
- 代价: 每个闭包各持一份环境, 数量多时内存压力变大;
- 释放: 把闭包引用置空, 环境才可能在下一次回收时清掉;

```js
let fn = makeBigClosure(); // 内部捕获了大块数据
fn = null;                 // 解除引用, 下次回收才收得掉
```

## 立即执行函数是什么?

- 形态: 定义一个函数表达式后立刻调用, 只执行一次;
- 作用: 造一个临时作用域, 里面的变量外面看不见;
- 为什么加括号: 语句以 function 开头会被当成声明, 括号把它拉回表达式;
- 其它写法: 前置 `!` 或 `+` 等一元运算符效果相同;
- 现状: let 与 const 已提供块级作用域, 新代码基本不再需要它;

```js
(function () {
  var message = "只在里面可见";
  console.log(message);
})();

console.log(typeof message); // "undefined"; 外面拿不到
```

## 闭包适合用在哪些场景?

- 私有状态: 计数器、缓存、只能通过方法读写的字段;
- 回调上下文: 防抖节流里保存定时器与最后一次参数;
- 函数工厂: 柯里化、偏函数, 给通用函数预置环境参数;
- 模块化: 立即执行函数返回公开接口, 内部实现不暴露;
- 一次性逻辑: 首次计算结果存进闭包, 后续直接复用;

```js
const once = (fn) => {
  let done = false;         // 闭包保存调用状态
  return (...args) => {
    if (done) return undefined; // 边界: 之后再调用一律返回 undefined
    done = true;
    return fn(...args);
  };
};
```

## 用闭包要防哪些坑?

- 循环变量: var 循环里所有回调共用一个变量, 结果全是最后一次的值;
- 内存泄漏: 闭包长期持有大对象或 DOM 节点, 页面不刷新就一直占着;
- 意外共享: 同一外层环境被多个闭包共用, 改一个会影响另一个;
- 调试困难: 变量真实取值取决于调用历史, 比普通函数难跟;

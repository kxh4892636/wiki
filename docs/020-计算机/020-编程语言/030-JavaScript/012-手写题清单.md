## 数组去重有哪些方式?

| 写法 | 判等口径 | 说明 |
| --- | --- | --- |
| `[...new Set(arr)]` | SameValueZero | 最短, 能去掉 NaN |
| `arr.filter` 加 indexOf | 严格相等 | 保留首次出现, 但 NaN 全丢 |
| `reduce` 加 includes | SameValueZero | 兼容老环境 |
| 双重循环加 splice | 严格相等 | 面试里最常见的手写 |
| Map 记标记 | SameValueZero | 大数组时线性最快 |

```js
const arr = [1, 2, 1, NaN, NaN, { a: 1 }, { a: 1 }];

[...new Set(arr)];                  // [1, 2, NaN, {a:1}, {a:1}]
arr.filter((v, i) => arr.indexOf(v) === i); // 两个 NaN 都被丢掉
arr.reduce((acc, v) => (acc.includes(v) ? acc : [...acc, v]), []);
// [1, 2, NaN, {a:1}, {a:1}]; 去掉 NaN 重复, 但对象按地址算
```

- 对象: 内容相同地址不同, 都会被保留; 要按 id 去重得自己写比较;
- 字符串: 大小写与首尾空白应先统一, 否则会被当成不同值;

## 手写去重要注意什么?

- 判等: indexOf 用严格相等, 认不出 NaN, 所以 filter 版会把 NaN 全丢掉;
- Set: 用 SameValueZero, NaN 等于自身, 通常直接选它;
- 顺序: 各写法都保留首次出现的顺序, 这一点要能说清;
- 复杂度: 双重循环是平方级, Map 与 Set 是线性;

```js
function unique(arr) {
  if (!Array.isArray(arr)) return []; // 边界: 非数组直接返回空
  const seen = new Map();             // SameValueZero 判等
  const result = [];
  for (const item of arr) {
    if (seen.has(item)) continue;     // 出现过就跳过
    seen.set(item, true);
    result.push(item);
  }
  return result;                      // 保持原顺序, O(n)
}
```

## 手写数组方法怎么下手?

- 共同结构: 新建容器, 遍历 this, 按语义决定往容器里放什么;
- map: 用回调返回值填新数组, 长度不变;
- filter: 回调为真才收进新数组;
- reduce: 有初值从第 0 项累加, 没有初值就拿第 0 项当初始值;
- flat: 递归摊平, 用深度计数控制层数;

```js
Array.prototype.myMap = function (fn, thisArg) {
  const out = [];
  for (let i = 0; i < this.length; i++) out.push(fn.call(thisArg, this[i], i, this));
  return out;
};

Array.prototype.myReduce = function (fn, init) {
  let i = 0;
  let acc = init;
  if (acc === undefined) { acc = this[0]; i = 1; } // 边界: 无初值时用首项
  for (; i < this.length; i++) acc = fn(acc, this[i], i, this);
  return acc;
};
```

- 稀疏数组: 原生 map 会跳过空位, 简化版通常不处理, 面试时可以主动说明;

## 手写 call 与 bind 用什么思路?

- call: 把函数临时挂到目标对象上调用, 用完删掉;
- apply: 同上, 只是实参以数组传入;
- bind: 返回新函数, 内部用 apply 固定 this 并拼接预置参数;
- 边界: 目标为 null 时退到全局对象, 这是非严格模式的行为;

```js
Function.prototype.myCall = function (ctx, ...args) {
  const target = ctx == null ? globalThis : Object(ctx); // 边界: null 退到全局
  const key = Symbol("fn");   // 用 Symbol 避免覆盖已有属性
  target[key] = this;
  const ret = target[key](...args);
  delete target[key];         // 用完清理, 别留下痕迹
  return ret;
};

Function.prototype.myBind = function (ctx, ...preset) {
  const fn = this;
  return function (...args) {
    return fn.apply(ctx, preset.concat(args)); // 预置参数在前
  };
};
```

- 原型与 new: 这两块自己在原型那一篇写一遍, 能顺带讲清原型链;

## Promise 类工具怎么写?

- all: 计数, 全部兑现后按原下标返回结果数组;
- 失败: 任意一项拒绝就整体拒绝, 不再等其它项;
- 空数组: 直接兑现成空数组;
- 说明: Promise 状态与事件循环在异步一篇, 这里只写聚合逻辑;

```js
function promiseAll(list) {
  return new Promise((resolve, reject) => {
    const results = new Array(list.length);
    let left = list.length;
    if (left === 0) return resolve(results); // 边界: 空数组立即兑现
    list.forEach((p, i) => {
      Promise.resolve(p).then((v) => {
        results[i] = v;                      // 按原下标放, 保证顺序
        if (--left === 0) resolve(results);
      }, reject);                            // 任一项失败整体失败
    });
  });
}
```

- 顺序: 结果顺序由下标决定, 与各项完成的先后无关;

# 深拷贝与浅拷贝差在哪, 深拷贝该怎么写?

## 常见问题

- 深拷贝与浅拷贝区别是什么？
- 如何实现深拷贝？

## 概念索引

- 浅拷贝: 只复制第一层, 子对象仍共享;
- 深拷贝: 递归复制每一层, 新旧对象完全独立;
- 引用类型: 拷贝问题的根源, 复制到的是地址;
- 循环引用: 两个对象互相指向, 递归会无限套下去;
- WeakMap: 记住旧对象到新对象的映射, 用来断掉循环;
- structuredClone: 内建深拷贝, 覆盖多数场景但有限制;

## 浅拷贝复制到哪一层?

- 语义: 造一个新容器, 把每个元素的引用搬过去;
- 结果: 改第一层不影响原对象, 改第二层会双向可见;
- 判据: 拷贝后新旧对象的子对象是否还是同一个地址;

```js
const a = [{ n: 1 }];
const b = [...a];      // 浅拷贝
b[0].n = 2;
console.log(a[0].n);   // 2; 子对象仍然是同一个
b.push({});
console.log(a.length); // 1; 长度各自独立
```

## 有哪些现成的浅拷贝写法?

| 写法 | 适用 | 备注 |
| --- | --- | --- |
| `{...obj}` | 对象 | 只复制可枚举自有属性 |
| `[...arr]` | 数组 | 依赖迭代器 |
| `Object.assign({}, obj)` | 对象 | 同名属性后者覆盖 |
| `arr.slice()` | 数组 | 不改变原数组 |
| `arr.concat()` | 数组 | 无参调用即复制 |

- 丢失项: 展开与 assign 都不复制不可枚举属性, 也不复制原型;
- 选型: 新代码优先展开语法, 一眼看清复制了什么;

## JSON 方案有哪些坑?

- 做法: `JSON.parse(JSON.stringify(obj))`, 一行搞定;
- 丢失: undefined、函数、symbol 值会被直接丢掉;
- 报错: 有循环引用时直接抛 TypeError;
- 变形: Date 变字符串, Map 与 Set 变空对象, RegExp 变成空对象;
- 结论: 只适合纯 JSON 数据, 不能当通用深拷贝;

```js
const src = { d: new Date(), f() {}, u: undefined, m: new Map([[1, 2]]) };
JSON.parse(JSON.stringify(src));
// { d: "2026-11-21T08:00:00.000Z" }; 函数、undefined、Map 全没了
```

## structuredClone 能覆盖多少?

- 能力: 内建函数, 支持循环引用、Date、Map、Set、ArrayBuffer;
- 限制一: 不能克隆函数、DOM 节点、Promise 等;
- 限制二: 类的实例会退化成普通对象, 原型丢失;
- 兼容: 老环境没有这个函数, 需要自己写或引 polyfill;

```js
const src = { m: new Map([[1, 2]]) };
src.self = src;                    // 制造循环引用
const copy = structuredClone(src); // 正常完成
copy.m.get(1);                     // 2
copy.self === copy;                // true
```

## 手写深拷贝怎么写?

```js
function deepClone(value, seen = new WeakMap()) {
  if (value === null || typeof value !== "object") return value; // 原始值与函数直接返回
  if (seen.has(value)) return seen.get(value);                  // 循环引用命中缓存
  if (value instanceof Date) return new Date(value.getTime());
  if (value instanceof RegExp) return new RegExp(value.source, value.flags);

  const copy = Array.isArray(value) ? []
    : value instanceof Map ? new Map()
    : value instanceof Set ? new Set()
    : Object.create(Object.getPrototypeOf(value));              // 保留原型

  seen.set(value, copy); // 必须在递归之前登记, 否则互相引用会爆栈

  if (value instanceof Map) {
    for (const [k, v] of value) copy.set(deepClone(k, seen), deepClone(v, seen));
    return copy;
  }
  if (value instanceof Set) {
    for (const v of value) copy.add(deepClone(v, seen));
    return copy;
  }
  for (const key of Reflect.ownKeys(value)) {
    copy[key] = deepClone(value[key], seen); // 覆盖 symbol 键与不可枚举属性
  }
  return copy;
}
```

- 循环引用: seen 先存后递归, 回头遇到同一个对象直接取副本;
- 键范围: Reflect.ownKeys 同时给出字符串键与 symbol 键;
- 函数: 按引用共用, 真要复制函数体只能 toString 再 eval, 不推荐;
- 深度: 嵌套极深时递归仍会爆栈, 可改写成显式栈的迭代版本;
- 验收: 至少覆盖循环引用、Date、Map、数组嵌套与原型保留;

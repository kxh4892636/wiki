# JavaScript 有哪些数据类型, 如何判断类型?

## 常见问题

- 简述 Javascript 的数据类型
- Javascript 中 == 与 === 的区别是什么？
- 简述 null 和 undefined 的区别
- Javascript 可以保存的最大数值是多少？
- 为什么 0.1 + 0.2 会丢失精度？
- 简述 typeof 和 instanceof 的原理

## 概念索引

- 原始值: 七种按值访问、不可变的类型;
- 引用值: 唯一的 object 类型, 变量里只放地址;
- typeof: 读内部类型标签, 返回小写字符串;
- instanceof: 沿原型链比对构造函数的原型对象;
- IEEE-754: 所有 number 共用的 64 位二进制编码;
- 安全整数: 双精度能精确表示整数的上界, 也是精度问题的根源;

## 数据类型如何分类?

- 原始值: undefined、null、boolean、number、string、symbol、bigint;
- 引用值: 只有 object, 数组、函数、日期、正则都归它;
- 存储: 原始值直接存进变量, 引用值的变量里存地址;
- 复制: 原始值赋值后互不影响, 引用值赋值后指向同一对象;
- 判等: 原始值比值, 引用值比地址;

```js
const a = 1;
const b = a;
b = 2;
console.log(a); // 1; 原始值复制后互不影响

const o1 = { n: 1 };
const o2 = o1;
o2.n = 2;
console.log(o1.n); // 2; 两个变量指向同一个对象
```

## typeof 与 instanceof 如何判断类型?

| 表达式 | 结果 |
| --- | --- |
| `typeof undefined` | `"undefined"` |
| `typeof null` | `"object"` |
| `typeof 1n` | `"bigint"` |
| `typeof Symbol()` | `"symbol"` |
| `typeof function () {}` | `"function"` |
| `typeof []` | `"object"` |

- 类型标签: typeof 直接读值的内部类型标签, 不做任何转换;
- 两个坑: null 被判成 object, 除函数外的引用值一律是 object;
- 未声明变量: typeof 一个没声明的名字不报错, 返回 "undefined";
- instanceof: 沿 __proto__ 逐跳比对 Class.prototype, 走不到就 false;
- 双重局限: 原始值恒为 false, 跨 iframe 时原型不同也会失效;

```js
[] instanceof Array;   // true
[] instanceof Object;  // true; 原型链终点是 Object.prototype
1 instanceof Number;   // false; 原始值不参与
Object.prototype.toString.call([]);   // "[object Array]"
Object.prototype.toString.call(null); // "[object Null]"
```

- 分工: 原始类型用 typeof, 引用类型用 toString, 继承关系用 instanceof;

## == 与 === 有什么区别?

- ===: 类型不同直接 false, 不做任何转换;
- ==: 类型不同时先按规则转换再比较;
- 转换方向: 布尔转 number, 字符串转 number, 对象转原始值;
- 特例: null == undefined 为 true, 且两者不与其它值宽松相等;
- NaN: 与任何值 (含自身) 的 == 与 === 都是 false;

```js
"1" == 1;            // true
"1" === 1;           // false
null == undefined;   // true
null === undefined;  // false
[] == false;         // true; 两边都转成 0
Object.is(NaN, NaN); // true; 唯一说 NaN 相等的比较
```

- 实践: 默认写 ===, 只有 `x == null` 这种判空是可读的例外;

## null 与 undefined 有什么区别?

- undefined: 声明了但没赋值, 表示"还没有值";
- null: 显式赋空, 表示"值就是没有";
- 常见来源: 未传的参数、无返回值的函数、不存在的属性都得 undefined;
- typeof: 前者是 "undefined", 后者是 "object";
- 转数字: Number(undefined) 是 NaN, Number(null) 是 0;
- 判空: `x == null` 一次命中两者, 比分别写两个 === 短;

## 最大数值与精度损失

- 编码: number 全是 IEEE-754 双精度, 1 位符号 + 11 位阶码 + 52 位尾数;
- 最大值: Number.MAX_VALUE 约 1.8e308, 再大就是 Infinity;
- 安全整数: 2 的 53 次方减 1, 即 9007199254740991, 再往上相邻整数会撞车;
- 0.1 与 0.2: 二进制表示都是无限循环小数, 存进内存时已被截断;
- 结果: 相加得 0.30000000000000004, 与 0.3 差一个极小量;
- 对策: 用 Number.EPSILON 比容差, 金额场景换算成整数再算;

```js
0.1 + 0.2 === 0.3;                          // false
Math.abs(0.1 + 0.2 - 0.3) < Number.EPSILON; // true
9007199254740993;                           // 9007199254740992; 撞车
```

- 超出安全整数: 用 bigint, 字面量末尾加 n;

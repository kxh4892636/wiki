# map 与 forEach 有什么不同, 对象又该怎么遍历?

## 常见问题

- 简述 map 与 foreach 的区别
- 遍历对象有什么方式？

## 概念索引

- map: 逐项映射, 返回等长新数组;
- forEach: 逐项执行副作用, 返回 undefined;
- 回调参数: 两者都是值与索引、原数组;
- keys 与 entries: 对象遍历的两个主要入口;
- for...in: 会带上原型链上的可枚举属性, 是常见的坑;
- 属性顺序: 整数键升序在前, 其余按插入顺序, symbol 在最后;

## map 与 forEach 有什么区别?

| 项 | map | forEach |
| --- | --- | --- |
| 返回值 | 等长新数组 | undefined |
| 用途 | 转换数据 | 执行副作用 |
| 链式调用 | 可接 filter、reduce | 不行, 返回 undefined |
| 中断 | 不能 | 不能, return 只跳过本次 |

- 共同点: 都遍历全部元素, 都不能用 break 提前退出;
- 稀疏数组: 两者都跳过空位, 对应回调不执行;
- 新数组: map 的每一项都是回调返回值, 忘写 return 会得到 undefined;

```js
const nums = [1, 2, 3];
nums.map((n) => n * 2);      // [2, 4, 6]; 有新数组
nums.forEach((n) => n * 2);  // undefined; 结果被丢弃
nums.map((n) => { n * 2; }); // [undefined, undefined, undefined]
```

## 想提前退出该用什么?

- some: 回调返回 true 就停, 结果是布尔值;
- every: 回调返回 false 就停, 结果是布尔值;
- find: 返回第一个满足条件的元素, 找不到是 undefined;
- for...of: 可以直接 break、continue、return;
- 结论: 需要中途停止时不要用 map 与 forEach;

```js
[1, 2, 3].some((n) => n > 1);  // true; 走到 2 就停
[1, 2, 3].every((n) => n < 3); // false; 走到 3 就停
for (const n of [1, 2, 3]) { if (n > 1) break; }
```

## 遍历对象有哪些方式?

| 方式 | 范围 | 含原型属性 |
| --- | --- | --- |
| `for...in` | 可枚举字符串键 | 含 |
| `Object.keys` | 可枚举自有字符串键 | 不含 |
| `Object.values` | 可枚举自有值 | 不含 |
| `Object.entries` | 可枚举自有键值对 | 不含 |
| `Object.getOwnPropertyNames` | 自有字符串键, 含不可枚举 | 不含 |
| `Reflect.ownKeys` | 自有全部键, 含 symbol | 不含 |

- 常用: 只要键用 keys, 键值一起用 entries 加解构;
- 冷门: 不可枚举属性只有 getOwnPropertyNames 与 Reflect.ownKeys 拿得到;
- 取舍: 只想读值用 values, 但要拿不到对应的键;

```js
const user = { a: 1, b: 2 };
Object.keys(user);    // ["a", "b"]
Object.entries(user); // [["a", 1], ["b", 2]]
for (const [k, v] of Object.entries(user)) console.log(k, v);
```

## for...in 的坑在哪?

- 原型链: 会遍历到原型上的可枚举属性, 给内建原型加东西时尤其危险;
- 修法: 用 `Object.hasOwn(obj, key)` 过滤掉继承来的键;
- 顺序: 整数键升序, 其余按插入顺序, 不要依赖这种顺序表达语义;
- 替代: 遍历自有属性一律用 keys、values、entries;

```js
Array.prototype.extra = 1; // 给原型加一个可枚举属性
const o = { x: 1 };
for (const k in o) console.log(k);               // x, extra
for (const k of Object.keys(o)) console.log(k);  // 只有 x
delete Array.prototype.extra;
```

## 属性顺序按什么排?

- 整数键: 按数值升序, 且一定排在所有字符串键之前;
- 字符串键: 按定义顺序;
- symbol 键: 一律排在最后, 也不会被 keys 遍历到;
- 注意: 顺序是规范约定的实现细节, 业务逻辑不应依赖它;

```js
const o = { b: 1, 2: 2, a: 3, 1: 4 };
Object.keys(o); // ["1", "2", "b", "a"]; 整数键升序, 其余按定义顺序
```

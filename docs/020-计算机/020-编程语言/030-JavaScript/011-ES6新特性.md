# ES6 带来了哪些新特性?

## 常见问题

- 简述 ES6 的新特性

## 概念索引

- 块级作用域: let 与 const 带来的新边界;
- 语法糖: 箭头函数、模板字符串、解构等书写形式;
- 新数据结构: Map、Set、Symbol 补齐对象能力;
- 类语法: 用 class 表达构造与继承;
- 模块: import 与 export 取代脚本拼接;
- 元编程: 用 Proxy 与 Reflect 拦截对象的基本操作;

## 声明与作用域变了什么?

- let 与 const: 块级作用域, 替代 var 的函数作用域;
- 暂时性死区: 声明之前访问抛 ReferenceError, 不再静默得到 undefined;
- const: 必须初始化, 绑定不可更换;
- 块级函数: 函数声明也能被限制在代码块内;

```js
{
  let a = 1;
  const b = 2;
}
typeof a; // "undefined"; 块外不可见
```

- 实践: 默认用 const, 需要重新赋值时才用 let, 基本不用 var;

## 哪些是书写层面的变化?

- 箭头函数: 不绑定 this 与 arguments, 也不能 new;
- 模板字符串: 反引号加插值, 支持换行;
- 解构赋值: 按位置或属性名一次取出多个值;
- 默认参数: 形参直接写默认值, 只在传 undefined 时生效;
- 剩余与展开: 同一个 `...` 符号两个方向, 收集或铺开;
- 对象简写: 属性名与变量同名只写一个, 方法可省掉 function;

```js
const name = "a";
const obj = { name, hi: () => 1 };
const { name: n } = obj;
const arr = [...[1, 2], 3];
const greet = (who = "world") => "hi " + who;
```

## 新增了哪些数据结构?

- Map: 键可以是任意类型, 保持插入顺序, 有 size;
- Set: 值唯一的集合, 天然用来去重;
- WeakMap 与 WeakSet: 键是弱引用, 不阻止回收, 不能遍历;
- Symbol: 唯一且不可重复的原始值, 常用作内部键;

```js
const m = new Map([["k", 1]]);
m.get("k"); // 1
[...new Set([1, 1, 2])]; // [1, 2]
Symbol("id") === Symbol("id"); // false; 每个都唯一
```

## 类与继承怎么写?

- class: 语法糖, 底层仍是构造函数加原型;
- 继承: extends 继承父类, super 调父构造或父方法;
- 差异: class 内部默认严格模式, 且只能通过 new 调用;
- 静态成员: static 挂在类本身, 不在原型上;
- 私有字段: `#name` 形式, 类外部访问不到;

```js
class Animal {
  constructor(name) { this.name = name; }
  speak() { return this.name; }
}
class Dog extends Animal {
  speak() { return super.speak() + ": woof"; }
}
new Dog("d").speak(); // "d: woof"
```

## 模块与元编程补了什么?

- 模块: export 导出、import 导入, 自动严格模式, 支持静态分析;
- 生成器: function* 搭配 yield, 得到可暂停的函数;
- 迭代器: 实现 Symbol.iterator 就能被 for...of 消费;
- Proxy: 拦截 get、set 等操作, 做响应式与参数校验;
- Reflect: 提供与拦截器一一对应的默认行为;

```js
const p = new Proxy({}, { get: () => "trapped" });
p.anything; // "trapped"
```

- 加载: 模块默认延迟执行, 依赖关系由引擎静态解析;

## 内建对象补了哪些方法?

| 类型 | 新增 |
| --- | --- |
| Array | from、of、find、findIndex、includes |
| Object | assign、keys、values、entries |
| String | includes、startsWith、padStart、repeat |
| Number | isNaN、isInteger、EPSILON、MAX_SAFE_INTEGER |
| Math | trunc、sign、cbrt 等 |

- Promise: 统一异步写法, 状态与执行顺序在异步一篇;
- 版本提醒: ES6 是 2015 年的版本号, 之后每年还有新特性, 别把它当终点;

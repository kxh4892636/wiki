# Go

按语言模型、类型、控制流、函数、接口、错误、并发、内存、工程与工具链组织 Go 知识体系。

<Mindmap>

# 1 Go

Go 是静态类型、编译型语言：用 goroutine 与 channel 表达并发，用接口做隐式抽象，用 GC 管理内存，用统一工具链构建与测试。

## 1.1 语言模型

静态类型、显式转换、组合优于继承；并发内建，工程工具统一。

### 1.1.1 静态类型与编译

类型在编译期检查，赋值与传参需要类型匹配；编译成单文件二进制，部署不依赖运行时环境。

> - [Go 优缺点与错误处理](007-Go优缺点与错误处理.md) doc:fbfe4610-3c5c-4d85-bbb6-b5a427d92733

### 1.1.2 goroutine 与 CSP

goroutine 是用户态轻量执行单元；CSP 主张通过 channel 通信共享数据，而不是直接共享内存。

> - [GMP 与 goroutine 调度](001-GMP与goroutine调度.md) doc:9f5d5de3-e7ab-41dd-bb6f-9d5446ba6c76

### 1.1.3 工具链与工程

go 命令统一构建、测试、格式化与依赖管理；module 定义版本边界，工程结构按职责分层。

## 1.2 词法与声明

源码以 package 组织，声明决定名字、类型与作用域。

### 1.2.1 源码规则

Go 源码是 UTF-8；语句分隔由编译器自动插入分号；包声明、导入与顶层声明有固定顺序。

### 1.2.2 变量与常量

var 声明变量，:= 做短变量声明；const 声明编译期常量，iota 生成枚举；未赋值变量取零值。

### 1.2.3 作用域

包级、函数级与块级作用域；内层同名变量遮蔽外层；首字母大写决定是否导出。

## 1.3 类型系统

类型由底层类型与字面类型决定；零值、可比较性与转换规则影响所有表达式。

### 1.3.1 类型基础与零值

每个类型都有零值；可比较类型才能做 ==、map key 与 switch；命名类型与底层类型区分。

### 1.3.2 基础类型

bool、整数、浮点、复数、string、byte 与 rune；string 不可变，rune 表示 Unicode 码点。

### 1.3.3 数组与 slice

数组长度是类型的一部分，赋值复制整个数组；slice 是描述符，赋值共享底层数组，append 可能扩容。

> - [slice 底层原理](004-slice底层原理.md) doc:210d79ad-aabb-4c35-871e-f369349fdb26

### 1.3.4 map 与 struct

map 是哈希表，key 必须可比较，并发读写不安全；struct 聚合字段，支持标签与嵌入。

> - [Map 实现](006-Map实现.md) doc:703bbb8b-a7c3-45fb-bd11-35a7da3925db

### 1.3.5 指针与 uintptr

指针保存地址，不支持算术；uintptr 是整数，只用于 unsafe 边界，不能当普通指针长期保存。

### 1.3.6 类型定义与转换

type 定义新命名类型，类型别名与原类型完全相同；转换要求底层类型兼容，接口转换在运行时检查。

### 1.3.7 泛型

类型参数让函数与类型适配多种类型；约束描述可用的操作；实例化在编译期完成，运行时无额外类型擦除成本。

## 1.4 表达式与控制流

运算符、条件与循环构成函数体；Go 只有 for 一种循环。

### 1.4.1 运算符

算术、比较、逻辑、位运算与赋值运算符；优先级固定，布尔表达式短路求值；不会隐式类型转换。

### 1.4.2 if 与 switch

if 可带初始化语句；switch 默认不穿透，case 可用表达式列表；type switch 按动态类型分支。

### 1.4.3 for 与 range

for 支持三段式、条件式与无限循环；range 遍历数组、slice、map、string、channel；range 取到的是元素副本。

## 1.5 函数与方法

函数是一等值，支持多返回值、可变参数与闭包；方法给类型绑定行为。

### 1.5.1 函数与多返回值

函数可返回多个值，error 常作为最后一个返回值；可变参数本质是 slice；闭包捕获外层变量。

### 1.5.2 defer

defer 把调用压入延迟栈，函数返回前按 LIFO 执行；参数在注册时求值，具名返回值可被修改。

> - [defer 执行顺序](005-defer执行顺序.md) doc:027b79ce-a72a-4a81-9f3a-2cb025024d62

### 1.5.3 方法与接收者

值接收者复制接收者，指针接收者可修改原值；方法集合决定接口实现与可调用范围。

### 1.5.4 方法集合与嵌入

类型嵌入把字段与方法提升到外层；方法集合由接收者类型决定；嵌入不是继承，调用仍走组合。

## 1.6 接口与动态类型

接口由方法集合定义；实现是隐式的，接口值保存动态类型与数据。

### 1.6.1 interface 声明与实现

接口声明方法集合；类型实现全部方法即满足接口，不需要显式声明；空接口可承载任意值。

### 1.6.2 interface 值

接口值由动态类型与动态值组成；nil 接口与“持有 nil 指针的接口”不同，判空要小心。

### 1.6.3 类型断言

类型断言把接口值还原为具体类型；comma ok 避免 panic；type switch 按动态类型分支。

## 1.7 错误与异常

错误是普通返回值；panic 只用于不可恢复的异常，recover 在 defer 中捕获。

### 1.7.1 error 返回与包装

error 是接口，nil 表示成功；用 %w 包装保留错误链，errors.Is 判断目标，errors.As 提取类型。

> - [Go 优缺点与错误处理](007-Go优缺点与错误处理.md) doc:fbfe4610-3c5c-4d85-bbb6-b5a427d92733

### 1.7.2 panic 与 recover

panic 触发栈展开，defer 依次执行；recover 只能在 defer 中生效；库边界可把 panic 转成 error。

## 1.8 并发

goroutine 表达并发任务，channel 与同步原语协调；调度器负责把 G 映射到 M 与 P。

### 1.8.1 goroutine

go 语句启动 goroutine，函数返回即结束；启动不等于完成，需要 channel、WaitGroup 或 context 等待。

### 1.8.2 GMP 调度

G 是 goroutine，M 是线程，P 是处理器上下文；本地队列、全局队列与 work stealing 共同调度。

> - [GMP 与 goroutine 调度](001-GMP与goroutine调度.md) doc:9f5d5de3-e7ab-41dd-bb6f-9d5446ba6c76

### 1.8.3 channel

channel 是 goroutine 间的通信管道；无缓冲是同步交接，有缓冲是队列；关闭表示不再发送。

> - [Channel 与并发安全](002-Channel与并发安全.md) doc:5cfdd006-7b84-49c7-b287-2b46bbf52fa7

### 1.8.4 select

select 同时等待多个 channel 操作；有就绪分支就执行，多个就绪随机选；default 提供非阻塞分支。

### 1.8.5 同步原语

Mutex 保护临界区，RWMutex 适合读多写少；WaitGroup 等待一组任务，Once 只执行一次，atomic 做无锁计数。

### 1.8.6 并发设计

明确数据所有者与退出条件；优先 channel 交接，共享状态必须统一加锁；用 race detector 检查竞争。

## 1.9 内存与 GC

变量可能分配在栈或堆；逃逸分析决定去向；GC 用三色标记与写屏障并发回收。

### 1.9.1 内存分配与逃逸

局部变量若逃逸到堆，由 GC 管理；返回指针、闭包捕获、接口装箱都可能导致逃逸；减少分配可降低 GC 压力。

### 1.9.2 三色标记与写屏障

白色未访问、灰色待扫描、黑色已扫描；并发标记时写屏障维护引用关系，辅助 GC 防止分配过快。

### 1.9.3 GC 触发与周期

GOGC 按堆增长触发，GOMEMLIMIT 设软上限；一次 GC 含短暂 STW 与并发标记清除；同一时间只运行一个 GC 周期。

> - [垃圾回收机制](003-垃圾回收.md) doc:07f616b9-36f7-403b-86e8-a6f553fbd1c9

## 1.10 程序组织

包是编译与可见性边界；module 管理依赖版本；工程结构表达职责。

### 1.10.1 包与可见性

package 声明包名，import 引入依赖；首字母大写导出；包初始化按依赖顺序执行 init。

### 1.10.2 module 与依赖

go.mod 声明模块路径与依赖版本；go.sum 校验内容；replace 可替换本地或特定版本。

### 1.10.3 工程结构

cmd 放入口，internal 放私有包，pkg 放可复用包；按职责分层，避免循环依赖。

## 1.11 工具链

go 命令覆盖构建、测试、依赖与静态检查；pprof 与 race 用于性能与并发问题。

### 1.11.1 go 命令

go build、run、test、mod、vet、fmt 是日常入口；交叉编译只需设置 GOOS 与 GOARCH。

### 1.11.2 测试与性能

testing 包写单元测试与基准；go test -race 查竞争；pprof 采 CPU、内存、goroutine 与阻塞 profile。

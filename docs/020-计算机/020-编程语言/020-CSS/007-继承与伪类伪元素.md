# CSS 的继承、伪类伪元素与替换元素分别是什么？

## 常见问题

- CSS 哪些属性是可以继承的
- 什么是可继承元素和不可继承元素？
- CSS 的伪类和伪元素的区别是什么？
- 什么是替换元素与非替换元素

## 概念索引

- 继承: 子元素未声明某属性时沿用父元素的计算值;
- 可继承属性: 以文字排版为主的属性;
- 不可继承属性: 盒模型与布局相关的属性;
- 伪类: 选中处于某状态或位置的元素;
- 伪元素: 选中元素的某一部分, 或额外生成一个子盒;
- 替换元素: 内容由外部资源决定、CSS 只管外框的元素, 与前三者共同决定一个元素最终长什么样、能不能被选中;

## 哪些属性可以继承？

| 类别 | 是否继承 | 例子 |
| --- | --- | --- |
| 字体与文字 | 是 | `font-family`、`font-size`、`font-weight`、`color` |
| 文本排版 | 是 | `text-align`、`text-indent`、`letter-spacing` |
| 列表 | 是 | `list-style`、`list-style-type` |
| 可见性与交互 | 是 | `visibility`、`cursor` |
| 盒模型 | 否 | `width`、`height`、`margin`、`padding`、`border` |
| 布局与定位 | 否 | `display`、`position`、`float`、flex 与 grid 属性 |
| 背景与变换 | 否 | `background`、`transform`、`box-shadow` |
| 生成内容 | 否 | `content`、`quotes` 中的具体值不继承 |

- 判断口径: 管"文字怎么排"的多半继承, 管"盒子怎么放"的多半不继承;
- `line-height` 特殊: 无单位数值被后代继承后, 各自乘以自身字号;
- 强制取值: `inherit` 取父值, `initial` 回初始值, `unset` 按是否可继承二选一;
- 一键重置: `all: unset` 把所有属性回到上述规则的结果;
- 规范: 每个属性页的 Inherited 一栏是最终裁判;

```css
button, input, textarea, select { font: inherit; color: inherit; }
```

## "可继承元素"这个说法准确吗？

- 结论: 不准确, 继承发生在属性上, 元素本身没有可继承与否;
- 原因: 同一个元素上 `color` 会继承, `margin` 不会;
- 常见误解: 以为 `a` 或 `button` 是"不可继承元素", 实际是浏览器默认样式覆盖了继承值;
- 表单控件: `input`/`button` 带 UA 默认样式, 加 `font: inherit` 即跟随父级;
- 表格: `table` 的 `border-collapse` 不继承, 但字体类属性照常继承;

```css
:root { color: #333; font: 16px/1.6 sans-serif; }
/* 没写颜色的元素都会拿到 #333, 包括 div、p、span、a */
```

- 记忆: 谈继承先问"哪个属性", 不要问"哪个元素";

## 伪类与伪元素有什么区别？

| 项 | 伪类 | 伪元素 |
| --- | --- | --- |
| 写法 | 单冒号 `:hover` | 双冒号 `::before` |
| 选中对象 | 处于某状态或位置的元素 | 元素的某部分或新生成的盒 |
| 是否生成新盒 | 否 | `::before`/`::after` 会 |
| 是否需 content | 否 | `::before`/`::after` 必须 |
| 权重 | 计一个类 | 计一个元素 |

- 常见伪类: `:hover`、`:focus-visible`、`:nth-child()`、`:has()`;
- 常见伪元素: `::before`、`::after`、`::first-line`、`::placeholder`;
- 历史写法: `:before` 单冒号是 CSS2 遗留, 浏览器仍认, 新代码统一双冒号;
- 用途分工: 伪类表达状态, 伪元素补装饰内容, 都不往 DOM 里加真节点;

```css
.btn:hover { background: #eef; }
.btn::after { content: "→"; margin-left: 4px; }
```

## 替换元素与非替换元素有什么区别？

| 项 | 替换元素 | 非替换元素 |
| --- | --- | --- |
| 内容来源 | 外部资源或控件内部 | 文档里的文本与子元素 |
| CSS 控制范围 | 外框尺寸与位置, 内部不归 CSS 管 | 内外都可控 |
| 尺寸 | 有固有尺寸, 可被 width/height 覆盖 | 由内容与盒模型决定 |
| 典型 | `img`、`video`、`iframe`、`input`、`canvas` | `div`、`p`、`span`、`a` |

- 固有尺寸: 图片有 `naturalWidth`, 不写宽高就按原图渲染;
- 适配: `object-fit: cover` 填满并裁剪, `contain` 保完整但留白;
- 基线空隙: 行内 `img` 底部多几像素, 用 `display: block` 消除;
- 半替换: `input` 只有外框与部分样式可改, 内部布局由浏览器决定;
- 规范: 见 [Replaced elements](https://developer.mozilla.org/en-US/docs/Web/CSS/Replaced_element);

```css
.thumb { width: 160px; height: 100px; object-fit: cover; display: block; border-radius: 6px; }
```

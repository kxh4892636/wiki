# CSS 工程化与常用技巧分别有哪些？

## 常见问题

- 如何解决 CSS 类名重名？
- 简述 CSS 有哪些上下文类型？
- 简述 CSS 预编译的方式
- 如何用 CSS 画三角形？
- CSS3 如何实现渐变色？
- CSS3 有哪些新特性

## 概念索引

- 命名冲突: 全局作用域下类名互相覆盖;
- 作用域隔离: 用命名约定、模块化或 Shadow DOM 限制影响范围;
- 格式化上下文: 决定子盒怎么排布的规则集合;
- 层叠上下文: 决定重叠元素谁在上面的独立层级;
- 预处理器: 构建期把扩展语法编译成 CSS 的工具;
- 绘制技巧: 用边框、渐变、裁切代替图片, 与前几项一起构成"写得稳又做得省"的 CSS 实践;

## 如何解决 CSS 类名重名？

| 方案 | 做法 | 优点 | 代价 |
| --- | --- | --- | --- |
| BEM 命名 | `block__element--modifier` | 零成本, 语义清晰 | 名字长, 靠人守规矩 |
| CSS Modules | 构建时把类名哈希化 | 真正隔离 | 需要构建配置 |
| CSS-in-JS | 样式写在组件里, 运行时生成 | 与组件同生命周期 | 有运行时开销 |
| Scoped | 给选择器加属性前缀 | 框架内置, 上手快 | 深度选择器易穿透 |
| 原子化 | 用工具类组合 | 无命名负担, 体积小 | 类名多, 可读性差 |
| Shadow DOM | 原生样式隔离 | 组件级彻底隔离 | 穿透需靠 CSS 变量 |

- 取舍: 中小项目 BEM 够用, 组件库选 CSS Modules 或原子化;
- 兜底: `@layer` 固定层顺序, 让基础样式永远压不过业务样式;
- 排查: 重名冲突的典型表现是"改了不生效", 用 DevTools 看被划掉的声明;

## CSS 有哪些上下文类型？

- 先分清: 格式化上下文管排布, 层叠上下文管遮挡, 两者不是一回事;
- BFC: 块级格式化上下文, 块盒纵向排, 内部浮动不外溢;
- IFC: 行内格式化上下文, 行内盒排在同一行, 受基线与 `line-height` 控制;
- FFC: 弹性格式化上下文, `display: flex` 建立, 按主轴排 item;
- GFC: 网格格式化上下文, `display: grid` 建立, 按轨道放置 item;
- 表格上下文: `display: table` 系列, 按行列算法布局;

| 上下文 | 触发 | 关键特性 |
| --- | --- | --- |
| BFC | `flow-root`、浮动、绝对定位、`overflow` 非 visible | 包含浮动, 隔离 margin |
| IFC | 块容器里出现行内内容 | 行盒、基线对齐、`text-align` |
| FFC | `display: flex` | 一维主轴, 可放大收缩 |
| GFC | `display: grid` | 二维轨道, 显式行列 |
| 层叠上下文 | 定位加 `z-index`、`opacity` 等 | 内部层级不与外部比较 |

### 怎么记才不混？

- 分工: 格式化上下文回答"怎么排", 层叠上下文回答"谁在上面";
- 近邻概念: 包含块决定偏移基准, 与上述两类都不同;

## CSS 预编译有哪几种方式？

- 预处理器: Sass、Less、Stylus, 提供变量、嵌套、混入, 构建期编译成 CSS;
- 后处理器: PostCSS 插件链, 补前缀、压缩、转换新语法;
- 原生能力: CSS 变量、原生嵌套、`@layer`、`color-mix()` 已覆盖多数老需求;
- CSS-in-JS: 在 JS 里写样式对象, 编译期或运行时生成 CSS;
- 接入: 构建工具加一个 loader 或插件, 与打包流程一起产出;

```scss
$brand: #3b82f6;
$brand-dark: #2563eb;
.card { color: $brand; &:hover { color: $brand-dark; } }
```

```css
/* 编译产物 */
.card { color: #3b82f6; }
.card:hover { color: #2563eb; }
```

- 选型: 新项目优先原生嵌套加 CSS 变量, 需要混入与数学函数再上 Sass;

## 如何用 CSS 画三角形？

- 原理: 四条边框在转角处斜接, 每个角对应一个梯形;
- 关键: `width: 0` 加 `height: 0`, 梯形退化成三角形;
- 方向: 哪条边上了颜色, 三角形就朝它的反方向;
- 变体: 只留两条边得到直角三角, 再加 `border-radius` 可做扇形;

```css
.tri {
  width: 0; height: 0;
  border: 40px solid transparent;
  border-bottom-color: #3b82f6; /* 指向上方 */
}
```

### 还有哪些画法？

- 替代: `clip-path: polygon(50% 0, 100% 100%, 0 100%)` 更适合不规则图形;
- 注意: 三角形占的是 border box, 会撑开布局, 必要时配合绝对定位;

## CSS3 有哪些新特性？

| 分类 | 特性 | 用途 |
| --- | --- | --- |
| 选择器 | `:nth-child`、`:not`、`:is`、`:has` | 精确匹配, 少加类 |
| 盒与视觉 | `border-radius`、`box-shadow`、`opacity` | 圆角、阴影、透明 |
| 颜色与图像 | 渐变、`color-mix()`、`oklch()` | 不依赖图片的底色 |
| 变换与动画 | `transform`、`transition`、`@keyframes` | 位移旋转与过渡 |
| 布局 | flex、grid、`gap`、多列 | 一维与二维布局 |
| 响应式 | 媒体查询、`clamp()`、容器查询 | 按环境切换布局 |
| 变量与层 | 自定义属性、`@layer`、`@scope` | 主题化与样式隔离 |

- 现状: flex、grid、自定义属性已是基础设施, 不该再当新特性讲;
- 演进: CSS3 之后规范按模块拆分, 新能力逐个模块发布;
- 选型: 上线前查 caniuse, 必要时用 `@supports` 做降级;

## CSS3 渐变怎么写？

- 线性: `linear-gradient(角度, 色标...)`, `0deg` 向上, `90deg` 向右;
- 径向: `radial-gradient(形状 尺寸 at 位置, 色标...)`;
- 锥形: `conic-gradient(from 角度 at 圆心, 色标...)`, 适合饼图与色环;
- 重复: 加 `repeating-` 前缀, 用像素间隔做出条纹;
- 本质: 渐变是 image 类型值, 可赋给 `background` 或 `border-image`;

```css
.hero { background: linear-gradient(135deg, #3b82f6, #9333ea); }
.pie { background: conic-gradient(#3b82f6 0 40%, #e5e7eb 40% 100%); border-radius: 50%; }
.stripe { background: repeating-linear-gradient(45deg, #eef 0 10px, #fff 10px 20px); }
```

### 渐变有哪些使用细节？

- 硬边: 两个色标写在同一位置, 就得到清晰的分界;
- 叠加: `background` 可写多层, 前面的盖在后面之上;
- 动画: 渐变本身不能过渡, 常用 `background-position` 做流动效果;

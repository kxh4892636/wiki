# 移动端适配有哪些方案, rem 与 em 有什么区别？

## 常见问题

- 移动端适配有哪些方案？
- rem 与 em 的区别以及使用场景

## 概念索引

- 布局视口: 页面排版所依据的逻辑屏幕宽度;
- dpr: 设备像素与 CSS 像素的比值;
- 媒体查询: 按视口特征切换样式;
- rem: 相对根元素字号的长度;
- em: 相对当前元素字号的长度;
- 根字号换算: rem 适配的核心, 由视口宽度反推 html 字号;

## 移动端适配要解决什么问题？

- 视口错位: 不写 viewport 声明时, 手机按 980px 虚拟宽度缩放整页;
- 像素差: 高分屏下一个 CSS px 对应多个物理像素, 1px 边框会显粗;
- 尺寸换算: 设计稿按 750 或 375 宽标注, 不同机型要等比缩放;
- 触控差异: 点击区域要够大, `:hover` 不可依赖;
- 目标: 同一套样式在不同宽度与像素密度下都合理;

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
```

- dpr 读取: `window.devicePixelRatio`, 常见取值 2 与 3;

## 移动端适配有哪些方案？

| 方案 | 做法 | 优点 | 代价 |
| --- | --- | --- | --- |
| 媒体查询 | 断点处各写一套 | 控制精确 | 断点多时维护重 |
| rem 缩放 | JS 设 html 字号, 全站用 rem | 等比缩放, 贴合设计稿 | 需要运行时脚本 |
| vw/vh | 直接用视口单位 | 纯 CSS, 无脚本 | 极端宽高比会失真 |
| 百分比加 flex | 流式布局 | 简单, 无换算 | 细粒度控制差 |
| 容器查询 | 按父容器宽度切换 | 组件级响应 | 旧浏览器不支持 |

- 大屏兜底: rem 方案要限根字号或限容器宽度, 否则平板上的字会巨大;
- 推荐组合: 流式布局做骨架, 媒体查询处理断点, rem 或 vw 处理字号;
- 1px 边框: 用 `transform: scaleY(0.5)` 或按 dpr 分支处理;
- 图片: 用 `srcset` 给 2x/3x 资源, 避免高分屏模糊;

## rem 与 em 有什么区别？

| 项 | rem | em |
| --- | --- | --- |
| 参照 | 根元素 `html` 的 font-size | 当前元素自身的 font-size |
| 递归 | 否, 全站一个基准 | 是, 逐层相乘 |
| 适合 | 字号、间距、栅格 | 组件内部的相对尺寸 |
| 风险 | 根字号一变全站变 | 嵌套深时尺寸失控 |

```css
html { font-size: 16px; }
.card { font-size: 20px; padding: 1em; }        /* 20px */
.card .title { font-size: 1.5em; padding: 1em; } /* 字号 30px, padding 30px */
.tag { padding: 1rem; }                          /* 恒为 16px */
```

- em 递归示例: 父字号 20px 时 `1.5em` 得 30px, 再往下 `1.5em` 就是 45px;
- 易错点: 给 `font-size` 写 em 时, 参照的是父元素字号, 不是自身;
- 选择: 组件内部用 em 让间距跟着字号走, 全局尺寸用 rem;

## 根字号怎么按视口换算？

- 思路: html 字号 = 视口宽 / 设计稿宽 × 基准字号;
- 常见比例: 750 设计稿下让 `1rem = 100px`, 系数就是 `clientWidth / 7.5`;
- 监听: `resize` 与 `orientationchange` 时重算, 首屏立即执行一次;
- 纯 CSS 替代: `font-size: 100vw / 7.5` 的效果用 `calc()` 写出, 不必等脚本;
- 上下限: 用 `clamp()` 锁住最小与最大字号, 大屏才不会失控;

```js
const setRoot = () => {
  const w = Math.min(document.documentElement.clientWidth, 750);
  document.documentElement.style.fontSize = w / 7.5 + "px"; // 750 稿, 100px 即 1rem
};
setRoot();
addEventListener("resize", setRoot);
```

```css
/* 免脚本写法, 与上面等价但会随视口无限放大, 所以加 clamp */
html { font-size: clamp(13px, calc(100vw / 7.5), 100px); }
```

### 两种写法怎么取舍？

- 注意: `100vw` 包含滚动条宽度, 桌面端可能与 `clientWidth` 不同;
- 取舍: 需要像素级还原设计稿用 rem 脚本方案, 否则 `clamp()` 更省事;

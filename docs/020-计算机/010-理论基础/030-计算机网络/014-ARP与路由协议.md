# ARP、OSPF、BGP 与 traceroute 分别解决什么问题？

## 常见问题

- 什么是 ARP 协议？简述其使用场景
- 简述 BGP 协议和 OSPF 协议的区别
- 简述 iPv4 和 iPv6 的区别
- traceroute 有什么作用？
- 简述 traceroute 命令的原理

## 概念索引

- 地址双层: IP 是网络层逻辑地址, MAC 是链路层接口地址, 只在本地链路有效;
- ARP: 在同一子网内把 IP 解析成 MAC;
- AS: 同一管理域下的一组路由器;
- OSPF: AS 内部的链路状态路由协议;
- BGP: AS 之间的路径向量协议;
- TTL: 报文允许的最大转发跳数;
- traceroute: 用逐跳超时反推路径, 与前面几个按「本地 / 域内 / 域间」分工;

## ARP 解决什么问题？

- 场景: 同一子网内知道对方 IP, 但要在链路上发帧, 必须有 MAC;
- 广播: 用 `FF-FF-FF-FF-FF-FF` 发 ARP 请求, 问「谁是这个 IP」;
- 应答: 目标主机单播回自己的 MAC;
- 缓存: 结果写进 ARP 表, 有老化时间, 过期重查;
- 跨子网: 解析的是网关的 MAC, 不是最终目标的 MAC;

```text
主机 A 发往 192.168.1.9 (不同子网)
ARP 问: 谁是 192.168.1.1 (网关)
拿到网关 MAC → 帧发给网关 → 网关再 ARP 下一跳
```

## ARP 有哪些风险？

- 无认证: 谁应答都信, 后到的应答会覆盖先前的;
- 欺骗: 伪造网关 MAC, 流量被引到攻击者, 成了中间人;
- 免费 ARP: 主机上线时主动通告, 也被用于抢地址;
- 防御: 静态绑定、交换机端口安全、动态 ARP 检测;

## OSPF 与 BGP 有什么区别？

| 项 | OSPF | BGP |
| --- | --- | --- |
| 范围 | AS 内部 | AS 之间 |
| 类型 | 链路状态 | 路径向量 |
| 算法 | Dijkstra 最短路 | 按策略选路 |
| 度量 | 链路开销, 人工设定 | AS 路径长度与策略属性 |
| 传输 | 直接跑在 IP 上 | TCP 179 |
| 目标 | 最快到达 | 按商业与策略关系可达 |

- OSPF: 泛洪链路状态, 每台路由器各自算最短路;
- BGP: 只与邻居交换可达前缀, 靠 `AS_PATH` 防环;
- iBGP 与 eBGP: 同一 AS 内与跨 AS 的两种会话;
- anycast: 多个机房通告同一前缀, BGP 把用户导向最近的一个;

## IPv4 与 IPv6 有什么区别？

| 项 | IPv4 | IPv6 |
| --- | --- | --- |
| 地址长度 | 32 位 | 128 位 |
| 表示 | 点分十进制 | 冒号十六进制, 可压缩 |
| 首部 | 20 字节起, 有检验和 | 固定 40 字节, 无检验和 |
| 分片 | 路由器可分片 | 只在源端分片 |
| 地址配置 | 手工或 DHCP | 可无状态自动配置 |
| NAT | 普遍使用 | 不再必需 |
| 广播 | 有广播 | 用组播与任意播替代 |

- 地址空间: IPv6 大到几乎不用再省地址;
- 迁移: 双栈与隧道并存, 隧道把 IPv6 包塞进 IPv4 里过老网络;
- 过渡期: 两种协议共存, 靠 DNS 记录类型与双栈主机适配;

## traceroute 如何工作？

```bash
traceroute example.com   # Linux: UDP 高端口, 逐次加 1
tracert example.com      # Windows: ICMP Echo
```

- 原理: 发 TTL=1 的包, 第一跳路由器减到 0 就回 ICMP 超时, 于是知道第一跳地址;
- 递进: TTL 从 1 加到 30, 逐跳收集地址与往返时间;
- 结束: 收到端口不可达 (UDP) 或 Echo Reply (ICMP);
- 用途: 定位路径、查环路、看从哪一跳开始丢包或延迟飙升;
- 局限: 中间设备可能不回 ICMP, 显示 `* * *`; 来回路径也可能不对称;

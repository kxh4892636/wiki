# 页面有哪些异步加载方式，readyState 又表示什么？

## 常见问题

- readyState 的不同返回值有什么区别？
- 简述异步加载的几种方式

## 概念索引

- defer: 并行下载, 解析完后按文档顺序执行;
- async: 并行下载, 下载完立即执行, 顺序不定;
- 动态脚本: 运行时创建 script 标签插入文档;
- 动态 import: ES 模块的按需加载;
- readyState: 文档或请求当前所处的阶段;
- DOMContentLoaded: DOM 解析完成, 不等图片;
- load: 所有资源加载完毕;

## async、defer 与普通脚本有什么区别？

| 方式 | 下载 | 执行时机 | 执行顺序 | 是否阻塞解析 |
| --- | --- | --- | --- | --- |
| 普通 script | 同步 | 下载完立即执行 | 文档顺序 | 是 |
| async | 并行 | 下载完立即执行 | 不确定 | 下载时不阻塞 |
| defer | 并行 | 解析完成后 | 文档顺序 | 否 |
| type=module | 并行 | 解析完成后 | 文档顺序 | 否 |

```text
解析 HTML:    =====A===========B=====
普通 script:      [下载][执行]        解析在此暂停
async:            [下载]        [执行]  任意时刻插入执行
defer:            [下载]              [执行] 解析结束后
```

- 有依赖关系的脚本: 用 defer 或 module, 保证顺序;
- 独立脚本: 统计、埋点用 async, 不拖累首屏;
- 注意: defer 脚本会在 DOMContentLoaded 之前执行;

## 运行时异步加载怎么做？

```js
function loadScript(src) {
  return new Promise((resolve, reject) => {
    const s = document.createElement('script')
    s.src = src
    s.async = false // 保序, 相当于动态版 defer
    s.onload = resolve
    s.onerror = reject
    document.head.append(s)
  })
}

await loadScript('/vendor/echarts.js')
const { lazy } = await import('./lazy-panel.js')
```

- 动态插入: 默认 async 行为, 设 async 为 false 可保序;
- 动态 import: 打包器会单独拆包, 用到才下载;
- JSONP: 用 script 绕过跨域, 只支持 GET;
- 预加载: preload 提前下载, 但执行仍要等标签插入;
- iframe: 旧方案, 隔离性好但成本高;

## document.readyState 有哪几个值？

| 值 | 含义 | 能做什么 |
| --- | --- | --- |
| loading | 文档仍在解析 | DOM 不完整, 只能等 |
| interactive | 解析完成, 资源未全到 | 可以操作 DOM |
| complete | 所有资源加载完毕 | 可读最终尺寸与高度 |

- 时机: interactive 与 DOMContentLoaded 几乎同时;
- 监听: 用 readystatechange 事件, 不要轮询;
- 常见写法: 先判断状态, 已就绪就直接执行;

```js
if (document.readyState === 'loading') {
  document.addEventListener('DOMContentLoaded', init)
} else {
  init() // 脚本晚于解析插入时直接跑
}
```

## XMLHttpRequest 的 readyState 是什么？

| 值 | 常量 | 含义 |
| --- | --- | --- |
| 0 | UNSENT | 还没调用 open |
| 1 | OPENED | 已调用 open |
| 2 | HEADERS_RECEIVED | 收到响应头 |
| 3 | LOADING | 正文接收中 |
| 4 | DONE | 请求结束 |

- 区别: 4 只代表流程走完, 成败要看 status;
- 判断: status 在 2xx 到 3xx 之间才算成功;
- 对比: fetch 用 Promise, 没有这套状态机;

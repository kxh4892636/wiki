# React 的生命周期是什么？

## 常见问题

- 简述 React 的生命周期

## 概念索引

- 挂载: 组件首次渲染并提交到 DOM;
- 更新: props 或 state 变化后重新渲染;
- 卸载: 组件从 DOM 移除;
- Effect: 用 setup / cleanup 表达生命周期;
- 依赖: 决定 Effect 何时重新同步;
- 清理: 下一次 setup 前与卸载时执行;

## 函数组件如何表达生命周期？

| 阶段 | 写法 | 执行时机 |
| --- | --- | --- |
| 挂载 | `useEffect(() => { setup; return cleanup; }, [])` | 首次提交后 |
| 更新 | `useEffect(() => { setup; return cleanup; }, [deps])` | 依赖变化后 |
| 卸载 | `return cleanup` | 组件移除前 |
| 绘制前 | `useLayoutEffect` | DOM 提交后、绘制前 |

```jsx
useEffect(() => {
  const sub = subscribe(roomId);
  return () => sub.unsubscribe();
}, [roomId]);
```

## 挂载与卸载时做什么？

- 挂载: 建立订阅、连接、定时器;
- 卸载: cleanup 取消订阅、断开连接、清除定时器;
- StrictMode: 开发期额外 setup + cleanup，检验可恢复;
- 服务端: Effect 不在服务端执行;

## 更新时做什么？

- 依赖变化: 先 cleanup 旧闭包，再 setup 新闭包;
- 空数组: 只在挂载时 setup，卸载时 cleanup;
- 省略依赖: 每次提交后重新同步;
- 依赖: 列出 setup 读取的所有响应式值;
- 竞态: cleanup 标记旧请求失效，防止旧结果覆盖;

## 常见误区

| 误区 | 后果 | 修正 |
| --- | --- | --- |
| 订阅不清理 | 重复注册、泄漏 | cleanup 取消订阅 |
| 空数组当挂载 | StrictMode 双跑 | 保证 cleanup 可撤销 |
| 在渲染中改 DOM | 渲染结果不可预测 | 放到 Effect |
| 依赖漏写 | 读到旧闭包 | 用 lint 检查依赖 |

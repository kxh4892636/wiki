# 什么是服务器渲染？Vue 和 React 是什么渲染模式？

## 概念索引

- 服务端渲染: 每次请求在服务端生成 HTML;
- 客户端渲染: 浏览器下载 JS 后生成 DOM;
- 静态生成: 构建期生成 HTML;
- 水合: 客户端接管服务端 HTML;
- 框架: React 用 Next.js，Vue 用 Nuxt 组合这些模式;

## 三种渲染模式有什么区别？

| 模式 | HTML 生成 | 首屏 | SEO | 适用 |
| --- | --- | --- | --- | --- |
| CSR | 浏览器 JS | 慢 | 弱 | 后台、强交互 |
| SSR | 每次请求服务端 | 较快 | 强 | 个性化、SEO |
| SSG | 构建期 | 最快 | 强 | 博客、文档 |
| 流式 SSR | 服务端分块 | 渐进 | 强 | 大页面、Suspense |

- 增量静态: 先返回静态页，后台再生成或更新;
- 混合渲染: 同一站点按路由选择不同模式;

## React 如何做 SSR？

```jsx
// server.js
import { renderToString } from "react-dom/server";
import App from "./App";

const html = renderToString(<App />);
res.send(`<div id="root">${html}</div>`);
```

```jsx
// client.js
import { hydrateRoot } from "react-dom/client";
import App from "./App";

hydrateRoot(document.getElementById("root"), <App />);
```

- renderToString: 同步生成 HTML 字符串;
- renderToPipeableStream: 流式输出，配合 Suspense;
- hydrateRoot: 客户端接管服务端 HTML;

## Vue 如何做 SSR？

```js
// server.js
import { createSSRApp } from "vue";
import { renderToString } from "vue/server-renderer";
import App from "./App.vue";

const app = createSSRApp(App);
const html = await renderToString(app);
```

```js
// client.js
import { createSSRApp } from "vue";
import App from "./App.vue";

createSSRApp(App).mount("#app");
```

| 框架 | CSR | SSR | SSG |
| --- | --- | --- | --- |
| React | createRoot | renderToString / renderToPipeableStream | 构建期 renderToString |
| Vue | createApp | createSSRApp + renderToString | Nuxt / Vite SSG |

## 水合为什么容易出错？

| 问题 | 原因 | 修正 |
| --- | --- | --- |
| 水合不匹配 | 服务端与客户端首次渲染不同 | 保证 props/state 一致 |
| 浏览器 API 报错 | 服务端没有 window | 放 Effect 或客户端组件 |
| 交互延迟 | JS 未加载完 | 减少包体、流式渲染 |
| 数据重复请求 | 服务端未传数据 | 序列化首屏数据 |

## 如何选择渲染模式？

- 内容站、文档: SSG + CDN;
- 个性化页面: SSR 或流式 SSR;
- 后台、强交互: CSR;
- 混合站点: 按路由选择;

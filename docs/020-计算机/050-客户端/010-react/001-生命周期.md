# React 的生命周期是什么？

## 概念索引

- 生命周期: 组件挂载、更新、卸载的固定阶段;
- 类组件: 用生命周期方法挂钩阶段;
- 函数组件: 用 Effect 表达同步与清理;
- 挂载: 首次插入 DOM;
- 更新: props 或 state 变化后重新渲染;
- 卸载: 从 DOM 移除并清理;

## 类组件生命周期有哪些阶段？

| 阶段 | 执行顺序 | 典型用途 |
| --- | --- | --- |
| 挂载 | constructor → getDerivedStateFromProps → render → componentDidMount | 初始化 state、订阅 |
| 更新 | getDerivedStateFromProps → shouldComponentUpdate → render → getSnapshotBeforeUpdate → componentDidUpdate | 对比前后值、测量 DOM |
| 卸载 | componentWillUnmount | 取消订阅、清定时器 |
| 错误 | getDerivedStateFromError → componentDidCatch | 降级 UI、记录错误 |

```jsx
class Chat extends React.Component {
  state = { roomId: "general" };

  componentDidMount() {
    this.sub = subscribe(this.state.roomId);
  }

  componentDidUpdate(prev) {
    if (prev.roomId !== this.state.roomId) this.resubscribe();
  }

  componentWillUnmount() {
    this.sub.unsubscribe();
  }

  render() {
    return <p>{this.state.roomId}</p>;
  }
}
```

- 旧方法: UNSAFE_componentWillMount / ReceiveProps / Update 不用于新代码;
- render: 纯函数，不订阅、不改 DOM;
- getSnapshotBeforeUpdate: 读取更新前 DOM，返回值传给 componentDidUpdate;

## 函数组件如何表达生命周期？

| 阶段 | 类组件 | 函数组件 |
| --- | --- | --- |
| 挂载 | componentDidMount | `useEffect(() => {...}, [])` |
| 更新 | componentDidUpdate | `useEffect(() => {...}, [deps])` |
| 卸载 | componentWillUnmount | `useEffect(() => () => cleanup, [])` |
| 绘制前 | getSnapshotBeforeUpdate | `useLayoutEffect` |

```jsx
useEffect(() => {
  const sub = subscribe(roomId);
  return () => sub.unsubscribe();
}, [roomId]);
```

## 常见误区

| 误区 | 后果 | 修正 |
| --- | --- | --- |
| constructor 里 setState | 无效或警告 | 直接赋值 this.state |
| 订阅不清理 | 重复注册、泄漏 | componentWillUnmount / Effect cleanup |
| 空数组当挂载 | StrictMode 双跑 | 保证 cleanup 可撤销 |
| 在 render 里改 DOM | 渲染结果不可预测 | 放到 Effect |

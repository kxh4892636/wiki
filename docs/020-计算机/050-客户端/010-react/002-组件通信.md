# React 组件间如何通信？

## 概念索引

- props: 父级向子级传只读输入;
- 回调: 子级把变更意图交回父级;
- 状态提升: 兄弟共享时移到共同父级;
- Context: 跨层传值，避免逐级透传;
- 外部 store: 跨页面共享状态;
- ref: 命令式访问子级或 DOM;
- children: 容器组合任意内容;

## 组件间有哪些通信方式？

| 方向 | 方式 | 适用 |
| --- | --- | --- |
| 父 → 子 | props | 常规数据 |
| 子 → 父 | 回调 props | 子级提出变更 |
| 兄弟 | 状态提升 | 共享同一份状态 |
| 跨层 | Context | 主题、用户 |
| 全局 | 外部 store | 跨页面共享 |
| 命令式 | ref / useImperativeHandle | 聚焦、滚动 |
| 内容 | children | 容器组合 |

```jsx
function Child({ value, onChange }) {
  return <input value={value} onChange={(e) => onChange(e.target.value)} />;
}

function Parent() {
  const [text, setText] = useState("");
  return <Child value={text} onChange={setText} />;
}
```

```jsx
const Theme = createContext("light");

function Button() {
  const theme = useContext(Theme);
  return <button className={theme}>OK</button>;
}
```

## 如何选择通信方式？

| 场景 | 选择 | 理由 |
| --- | --- | --- |
| 只有一个组件用 | 本地 state | 减少数据通道 |
| 兄弟需要同步 | 状态提升 | 单一来源 |
| 多层透传 | Context | 避免逐级 props |
| 跨路由或高频更新 | 外部 store | 脱离组件树 |
| 命令式操作 | ref | 只暴露必要能力 |

## 常见误区

| 误区 | 后果 | 修正 |
| --- | --- | --- |
| 复制 props 到 state | props 更新不同步 | 直接用 props，或改 key 重置 |
| 用 Effect 同步 state 副本 | 多一份状态、易循环 | 保留单一来源 |
| 用 ref 存渲染数据 | 变化不触发渲染 | 用 state |
